This profile is a **legacy script-based** sample (CustomScripts / `public.script.item`).

For Hello IT **1.7+**, prefer:

- Configurator Mode → Export → `.mobileconfig`, or
- The native samples under `Basic Example/`, `system_info/`, `munki_related/`, and `send_email/`

Keep this file only if you need a historical MDM layout that still ships scripts.
