##### Author: [Zack McCauley](https://www.github.com/WardsParadox)

### Description

**Hello IT 1.7+:** Prefer built-in `public.system.info` for hostname, storage, uptime, and memory (see the sample plist and `../system_info/ReadMe.md`).

CustomScripts in this folder remain useful for values with **no** built-in yet (serial, model, macOS version, SMART) or special click behaviour (e.g. uptime click-to-restart, email computer info — prefer `public.send.email` when you only need a mailer).

Most scripts were based on work by [Emily K/smashism](https://www.github.com/smashism) and updated by [Zack McCauley/WardsParadox](https://www.github.com/WardsParadox).
